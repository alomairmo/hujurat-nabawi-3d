# ملفات المجسم

شغّل مولّد Blender من جذر المشروع لإنشاء الملفات الأربعة هنا:

```bash
blender --background --python src/model.py
```

الملفات الناتجة:

- `exterior.glb` و`exterior.blend` للمشهد الخارجي.
- `interior.glb` و`interior.blend` للحجرة الداخلية.

ملفات GLB مطلوبة قبل تشغيل الصفحة، وملفات Blend متاحة للتحرير في Blender.
