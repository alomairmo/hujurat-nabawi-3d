# في رحاب العهد النبوي — مجسم تفاعلي

نسخة مطوّرة من مشهد المسجد والحُجُرات، مبنية بالاستناد إلى المخطط والصور المرجعية المرفقة.

## المناظر

- **المشهد العام:** خمس وحدات في الصف الشرقي وأربع في الصف الشمالي، ولكل وحدة حجرة وحوش.
- **دخول الحجرة:** بيت من مجلس أمامي وغرفة نوم خلفية بينهما جدار ومدخل. تعرض غرفة النوم مرحلتين: في حياة النبي ﷺ بلا قبور، ثم بعد الوفاة والدفن مع القبور والستار الفاصل.
- **الأدوات:** منظر قريب يضم ١٦ تسمية تفاعلية للأدوات والأواني، ومنها الرحى والسلة والزير والقِرَب.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

المشروع أمامي فقط ولا يحتاج حسابًا أو قاعدة بيانات. تعتمد المعاينة على Three.js وGLB وأصول محلية، ولا يمثل التوزيع أو شكل الأدوات توثيقًا أثريًا قاطعًا.

تفاصيل الأصول الخارجية والمخصصة في `CREDITS.md`.
