# في رحاب العهد النبوي

تجربة ويب عربية تفاعلية تستعرض تصورًا تقريبيًا للمسجد النبوي والحُجُرات المحيطة به بعد التوسعة النبوية، نحو سنة ٧هـ، مع إمكانية الانتقال إلى منظر داخلي مكشوف مستوحى من النموذج المتحفي المرفق لحجرة عائشة رضي الله عنها.

## المزايا

- مشهدان ثلاثيا الأبعاد: المسجد والحُجُرات من الخارج، والحجرة من الداخل.
- تسع حُجُرات مسماة مستلهمة من الصور المرجعية، ولكل حجرة فناء وسياج وبطاقة مستقلة.
- منظر داخلي مفصّل يضم السرير والغطاء المنسوج والوسائد والفراش والسجادة والقِرب ووعاء الماء والفاصل القماشي ومواضع القبور، ولكل عنصر بطاقة تعريفية.
- تنبيه زمني واضح: ظهور القبور يجعل المنظر الداخلي ممثلًا لمرحلة لاحقة، لا لهيئة الحجرة في سنة ٧هـ.
- تدوير المشهد وتقريبه والنقر على العناصر والبطاقات.
- بطاقات عربية تعرض اسم كل عنصر ووصفه ومرجعه.
- اختبار من ستة أسئلة مع التصحيح والشرح والنتيجة.
- واجهة عربية متجاوبة مع الحاسوب والهاتف.
- ملفات GLB وBlend للنموذجين داخل `public/models/`.

## التشغيل والبناء

```bash
npm install
npm run dev
npm run build
```

ناتج البناء يوجد في `dist/`. نقطة دخول التجربة هي `src/scene.js`، وبيانات البطاقات والاختبار في `src/content.js`. يمكن إعادة توليد النموذجين بتشغيل `src/model.py` عبر بيئة Blender المناسبة.

> هذا تصور تعليمي تقريبي، وليس إعادة بناء أثرية حاسمة للتوزيع أو المقاسات. أسماء الحُجُرات وملامحها الخارجية مستلهمة من الصور المرجعية، والمنظر الداخلي يتبع النموذج المتحفي المرفق في مرحلة زمنية لاحقة للمشهد الخارجي. لا تُحفظ نتيجة الاختبار بعد إغلاق الصفحة.
