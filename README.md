# في رحاب العهد النبوي — مجسم تفاعلي

نسخة مطوّرة من مشهد المدينة والمسجد والحُجُرات، مبنية بالاستناد إلى المخطط والصور المرفقة والمقطع المرئي «تصميم ثري دي للمدينة المنورة في عهد الرسول صل الله عليه وسلم».

## المناظر

- **المشهد العام:** نسيج من بيوت المدينة الطينية ذات الأسقف المسطحة والأزقة الترابية، تحيط به بساتين النخيل والحقول وقنوات السقي. وفي الوسط المسجد بصحنه المكشوف وظلال السعف، وخمس وحدات في الصف الشرقي وأربع في الصف الشمالي، ولكل وحدة حجرة وحوش.
- **دخول الحجرة:** بيت من مجلس أمامي وغرفة نوم خلفية بينهما جدار ومدخل. تعرض غرفة النوم مرحلتين: في حياة النبي ﷺ بلا قبور، ثم بعد الوفاة والدفن مع القبور والستار الفاصل.
- **الأدوات:** منظر قريب يضم ١٦ تسمية تفاعلية للأدوات والأواني، ومنها الرحى والسلة والزير والقِرَب.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

المشروع أمامي فقط ولا يحتاج حسابًا أو قاعدة بيانات. يبدأ بتحميل المشهد الخارجي، ثم يحمّل الحجرة ونماذج GLB المخصصة عند دخولها فقط لتسريع الفتح دون تقليل التفاصيل. تعتمد المعاينة على Three.js وأصول محلية، ولا يمثل التوزيع أو شكل الأدوات توثيقًا أثريًا قاطعًا.

تفاصيل الأصول الخارجية والمخصصة في `CREDITS.md`.
